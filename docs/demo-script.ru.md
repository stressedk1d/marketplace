# Сценарий защиты VogueWay (5–7 минут)

Репетируйте на **staging** (http://5.42.112.54 или vogueway.ru) с заранее созданным аккаунтом админа (`ADMIN_EMAILS`).

## 1. Главная (~1 мин)

- Показать hero, бренды, коллекции знаменитостей
- Если заранее открывали 2–3 товара одного бренда — блоки **«Недавно смотрели»** и **«Рекомендуем»**
- Fallback: сразу перейти в каталог

## 2. Каталог и поиск (~1,5 мин)

- Фильтр по бренду (Nike / Adidas)
- Сортировка по цене
- Текстовый поиск в шапке
- **Визуальный поиск** (загрузить фото) — предупредить: первый запрос может быть медленным  
  **Fallback:** «если AI недоступен — используем фильтры и текстовый поиск»

## 3. Карточка товара (~1 мин)

- Галерея, размер, отзывы
- Добавить в **избранное** и **сравнение** (до 3 товаров)
- «Поделиться» ссылкой на товар

## 4. Корзина и checkout (~1,5 мин)

- Войти (корзина только для авторизованных)
- Оформить заказ: имя, телефон, адрес
- Промокод **WELCOME10** (−10%) или **SAVE500** (от 3000 ₽)
- Показать блок **лояльности** (+1% баллов)
- После заказа — toast с номером и баллами

## 5. Заказы и личный кабинет (~0,5 мин)

- «Мои заказы» — статус, состав, **адрес доставки**
- Account — баллы лояльности

## 6. Админ-панель (~1 мин)

- Войти под admin-email
- Статистика + **графики** за 7 дней
- Сменить статус заказа: created → paid → shipped → delivered
- Показать адрес доставки в таблице заказов

## 7. Дополнительно (если спросят)

- Compare `/compare`
- Maintenance mode
- Open Graph — вставить ссылку на товар в мессенджер

## Чеклист перед выходом на защиту

```bash
cd backend && pytest
cd frontend && npm run build
```

- Миграции `0014–0016` применены на сервере
- `SECRET_KEY` не `change-me`
- Промокоды в БД: `WELCOME10`, `SAVE500`

## Известные ограничения (честно озвучить)

- Оплата и доставка — демо (данные сохраняются, платёжный шлюз не подключён)
- Восстановление пароля — ссылка на поддержку, без email-reset API
- Compare и недавние просмотры — localStorage, не синхронизируются между устройствами
